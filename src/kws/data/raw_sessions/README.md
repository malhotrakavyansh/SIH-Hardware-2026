# Raw Sessions

Drop raw, unsplit Audacity recordings here. Each file is one continuous take
containing ~25 repetitions of the wake word ("Nakshatra"), recorded before
splitting into individual per-utterance clips.

## Filename convention

```
<speaker>_session<N>_raw.wav
```

Example: `harshit_session1_raw.wav`

- `<speaker>`: recorder's first name, lowercase
- `<N>`: session number for that speaker, starting at 1
